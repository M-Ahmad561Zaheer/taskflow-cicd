About TaskFlow Project

TaskFlow is a state-of-the-art Task Management System built as a part of our Automated Software Testing & DevOps laboratory curriculum. The system utilizes a fully automated CI/CD pipeline powered by GitHub Actions and Docker containerization.

🚀 CI/CD Infrastructure Specifications

  • Continuous Integration (CI): Automated triggers on Pull Requests to develop branch utilizing docker/login-action.
  • Container Registry: Multi-tagged Docker Images (latest & ${{ github.sha }}) pushed successfully to Docker Hub.
  • Continuous Deployment (CD): Static source routing integrated seamlessly with Vercel Production Environment.
  • Base Image Optimization: Standard Nginx Alpine distribution ensuring minimal disk footprint and ultra-fast hosting.
